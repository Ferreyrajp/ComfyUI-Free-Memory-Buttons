# ComfyUI Free Memory Buttons

Botones flotantes y arrastrables para liberar VRAM y RAM en ComfyUI.

## Instalación
cd ComfyUI/custom_nodes
git clone https://github.com/TU_USUARIO/ComfyUI-Free-Memory-Buttons free_memory_buttons

Reiniciá ComfyUI y refrescá el navegador con Ctrl+F5.

## Uso
- Liberar VRAM: descarga los modelos de la GPU
- Liberar RAM: limpia la caché
- Liberar TODO: ambos
